O meni

Zvonimir Švaganović

Full-stack developer

Bavim se razvojem web i mobilnih aplikacija koristeći HTML i CSS, odnosno C# i .NET MAUI framework. .NET MAUI je Microsoftov alat za izradu cross-platform aplikacija za Android, iOS, Windows i macOS pomoću C#-a.

U slobodno vrijeme igram šah i stolni tenis. Volim igre koje zahtijevaju strategiju i optimizaciju što mi pomaže i u programiranju. Cilj mi je naučiti REST API i integrirati ga u svoje projekte.

Zašto .NET MAUI?

📱

Cross-platform

Jedan projekt, više platformi. MAUI omogućuje dijeljenje logike i resursa između mobilnih i desktop sustava, što skraćuje vrijeme razvoja i održavanja.

🎨

XAML UI/UX

Korisničko sučelje gradim u XAML-u pomoću data bindinga i stilova. Layouti se prilagođavaju različitim veličinama ekrana. Dosta vremena odvajam za UI/UX kako bih stvorio ugodan osjećaj korisnicima.

⚙️

C# backend

C#, LINQ i async/await patterns koristim za backend razvoj, lokalnu kao i mrežnu pohranu. Svoje projekte izrađujem koristeći Visual Studio IDE te svoje C# kodove organiziram pomoću #region-a.
